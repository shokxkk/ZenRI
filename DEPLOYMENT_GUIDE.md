# 🚀 Руководство по Деплою ZenRI и Подключению Своего Домена

Это пошаговое руководство для запуска **ZenRI** онлайн на вашем собственном домене, чтобы вы могли использовать его на своём **iPhone 17 Pro Max** как полноценное нативное веб-приложение (PWA) в 1 клик!

---

## 🌟 Вариант 1: Деплой на Vercel (Самый простой и бесплатный способ)

Vercel — это официальная платформа для Next.js приложений с бесплатным SSL-сертификатом (HTTPS) и поддержкой своего домена.

### Шаг 1: Подготовка базы данных PostgreSQL
Приложению нужна PostgreSQL БД онлайн. Вы можете бесплатно получить PostgreSQL ссылку за 1 минуту:
- [Neon.tech](https://neon.tech) (Бесплатный вечный PostgreSQL)
- [Supabase.com](https://supabase.com) (Бесплатный PostgreSQL)

Получите строку подключения, например:
`postgres://user:password@ep-cool-name.us-east-2.aws.neon.tech/neondb?sslmode=require`

### Шаг 2: Загрузка проекта на GitHub
1. Создайте репозиторий на [GitHub.com](https://github.com).
2. Загрузите код папки `ZenRI` в ваш репозиторий.

### Шаг 3: Деплой на Vercel
1. Перейдите на [Vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **«Add New» ➔ «Project»** и выберите ваш репозиторий `ZenRI`.
3. В разделе **Environment Variables** добавьте переменные среды:
   - `DATABASE_URL` = *Ваша PostgreSQL ссылка из Шага 1*
   - `NEXTAUTH_SECRET` = `zenri_super_secret_key_2026_x90284`
   - `NEXTAUTH_URL` = `https://ваш-домен.com` (или временный URL от Vercel)
   - `AISHA_STT_API_KEY` = `MAw6WUgS.SRBPzk0ZCogC2TxhUF3FCsjOkuapRIM5`
4. Нажмите **Deploy**. Vercel автоматически соберет и запустит проект!

### Шаг 4: Привязка Вашего Купленного Домена
1. В панели Vercel зайдите в ваш проект ➔ **Settings ➔ Domains**.
2. Введите ваш домен (например: `zenri.uz` или `myzenri.com`).
3. Vercel покажет 2 DNS записи для вашего регистратора доменов (где вы покупали домен):
   - **A Record**: `76.76.21.21` (для главного домена `@`)
   - **CNAME Record**: `cname.vercel-dns.com` (для `www`)
4. Пропишите эти записи в настройках вашего домена. В течение 5-10 минут ваш сайт станет доступен по вашему домену с автоматическим защищенным **HTTPS**!

## 📱 Как установить ZenRI на ваш iPhone 17 Pro Max как Приложение

После того как сайт заработает по вашему домену:

### Способ A: Через Chrome на iPhone
1. Откройте **Chrome** на айфоне и перейдите по вашему домену (`https://ваш-домен.com`).
2. Нажмите **три точки (Меню)** в углу экрана.
3. Выберите **«Добавить на главный экран»** (или «Отправить на экран "Домой"»).

### Способ B: Через Safari (Рекомендуется для iOS)
1. Откройте **Safari** на айфоне и зайдите на ваш сайт.
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой вверх внизу экрана).
3. Прокрутите вниз и нажмите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**.

🎉 **Готово!** На рабочем столе вашего iPhone 17 Pro Max появится фирменная иконка **ZenRI**. При клике приложение откроется во весь экран без рамок браузера как нативная программа!
